گزارش ادغام Marketplace Pro — فازهای 01 تا 20
================================================

وضعیت: بسته تجمیع‌شده با اصلاحات اولیه؛ هنوز تأییدشده برای production نیست.

اقدامات ادغام و اصلاح:
- ادغام فایل‌های 20 بسته در ساختار واحد Laravel 12.
- نگهداری راهنماهای فازها در docs/phase-guides.
- انتخاب نسخه جدیدتر کنترلرها و viewهای سفارش فروشنده از فاز 5.
- جلوگیری از ساخت دوباره جدول coupons و استفاده از migration توسعه‌ای.
- مرتب‌سازی migrationهای seller_orders، seller_order_items، payout_requests و seller_wallet_transactions برای رعایت وابستگی کلیدهای خارجی.
- ثبت alias میان‌افزار role در bootstrap/app.php.
- افزودن Laravel Sanctum به وابستگی‌های Composer برای API نسخه 1.
- اصلاح closure سرویس پرداخت برای دریافت صحیح SellerWalletService هنگام ثبت اعتبار فروشنده.
- اصلاح نگاشت فیلدهای قدیمی و جدید کوپن و کنترل سقف درصد پیش از نگاشت enum.
- اصلاح namespace separatorهای خراب در فایل‌های PHP پایه.

بررسی‌های انجام‌شده:
- بررسی نحوی با php -l روی تمام 176 فایل PHP: بدون خطا.
- بررسی فایل‌های include مسیرها: همه فایل‌های مورد اشاره وجود دارند.
- بررسی تکراری‌بودن نام جدول‌های Schema::create: مورد تکراری مشاهده نشد.
- composer validate اجرا نشد؛ Composer در محیط ساخت در دسترس نبود.
- اجرای route:list، migrate، تست‌های PHPUnit و build فرانت‌اند انجام نشد؛ vendor نصب نیست و محیط دیتابیس/Node پروژه پیکربندی نشده است.

محدودیت‌های مهم:
- Checkout سرتاسری هنوز کامل نیست و باید Cart، کوپن، هزینه ارسال، تفکیک سفارش و پرداخت را به هم متصل کند.
- درگاه پرداخت واقعی پیاده‌سازی نشده و ExampleGateway عمداً غیرفعال است.
- API به نصب Composer و پیکربندی نهایی Sanctum نیاز دارد؛ ورود/صدور توکن API کامل نیست.
- اتصال خودکار شرکت حمل‌ونقل، سیاست کامل refund و برخی CRUDها/رویدادهای اعلان تکمیل نشده‌اند.
- تست سرتاسری، امنیتی، بار و بررسی رفتار روی دیتابیس واقعی انجام نشده است.

این گزارش صرفاً نتیجه بررسی ایستای سورس و syntax lint را ثبت می‌کند؛ موفقیت اجرای برنامه یا آمادگی انتشار را تضمین نمی‌کند.
