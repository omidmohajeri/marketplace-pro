# فاز دوم — ورود، ثبت‌نام و سبد خرید

## ادغام فایل‌ها
فایل‌های این بسته را در ریشه پروژه فاز اول استخراج کنید و مسیرها را حفظ کنید.

## ثبت میان‌افزار نقش
در Laravel 12 فایل `bootstrap/app.php` را باز کنید و در callback مربوط به `withMiddleware` این alias را اضافه کنید:
```php
$middleware->alias([
    'role' => \App\Http\Middleware\EnsureRole::class,
]);
```

## افزودن مسیرها
محتوای `routes/web-phase2.snippet.php` را به `routes/web.php` اضافه کنید. آن فایل snippet است تا مسیرهای موجود فاز اول را بازنویسی نکند.

## مدل‌های موردنیاز
این فاز به مدل‌ها و جداول `users`, `carts`, `cart_items`, `products` فاز اول وابسته است.

## نکات امنیتی
- نقش هنگام ثبت‌نام همیشه `customer` است و از ورودی کاربر گرفته نمی‌شود.
- تغییر سبد خرید فقط برای مالک همان سبد مجاز است.
- موجودی هنگام افزودن به سبد دوباره بررسی می‌شود.
- در محیط عملیاتی حتماً HTTPS، محدودسازی نرخ ورود، تأیید ایمیل/شماره تلفن و تست امنیتی فعال شود.
