# فاز سوم — پنل مدیریت

## فایل‌های این فاز
- داشبورد آمار مدیریتی
- مدیریت کامل محصولات فروشگاه اصلی
- مدیریت دسته‌بندی‌های دوزبانه
- بررسی و فعال/معلق‌کردن فروشندگان و تعیین کمیسیون
- فهرست سفارش‌ها، جزئیات و تغییر وضعیت عملیاتی

## ادغام
1. فایل‌های ZIP را در ریشه پروژه اصلی استخراج کنید.
2. محتوای `routes/admin-phase3.snippet.php` را به انتهای `routes/web.php` اضافه کنید.
3. مطمئن شوید در `bootstrap/app.php` این alias تعریف شده است:
   ```php
   $middleware->alias([
       'role' => \App\Http\Middleware\EnsureRole::class,
   ]);
   ```
4. سپس اجرا کنید:
   ```bash
   php artisan optimize:clear
   php artisan route:list
   ```

## ایجاد مدیر اولیه
برای امنیت، ثبت‌نام عمومی هرگز نقش admin نمی‌سازد. پس از نصب، یک مدیر را از طریق Tinker ایجاد کنید:
```bash
php artisan tinker
```
سپس:
```php
\\App\\Models\\User::create([
    'name' => 'Site Administrator',
    'email' => 'admin@example.com',
    'password' => bcrypt('CHANGE_THIS_TO_A_LONG_RANDOM_PASSWORD'),
    'role' => 'admin',
    'locale' => 'fa',
]);
```
رمز نمونه را حتماً با رمز طولانی و منحصربه‌فرد جایگزین کنید.

## نکات عملیاتی
- همه مسیرهای `/admin` پشت احراز هویت و نقش admin هستند.
- وضعیت «پرداخت‌شده» نباید صرفاً از فرم مدیر یا کاربر پذیرفته شود؛ اتصال درگاه و callback امضاشده در فاز پرداخت پیاده‌سازی می‌شود.
- این نسخه مدیریت پایه است؛ گزارش‌های مالی حسابداری، گردش تأیید چندمرحله‌ای و ثبت Audit Log در فازهای تکمیلی افزوده می‌شوند.
