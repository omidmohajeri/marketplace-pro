فاز 11 Marketplace Pro — جست‌وجوی پیشرفته و فیلتر هوشمند
================================================================

امکانات این فاز:
- جست‌وجوی نام و توضیحات محصول
- فیلتر دسته‌بندی، بازه قیمت، موجودی و فروشنده
- مرتب‌سازی قیمت، جدیدترین و پرفروش‌ترین
- صفحه نتایج با صفحه‌بندی

نصب و ادغام:
1) از پروژه فعلی نسخه پشتیبان تهیه کنید.
2) فایل‌های پوشه‌های app، database، resources و tests را در مسیر متناظر ادغام کنید.
3) فایل route این فاز را طبق نام و توضیحات آن به routes/web.php یا routes/api.php منتقل کنید.
4) وابستگی‌ها، نام ستون‌ها، رابطه‌ها، middlewareها و layoutها را با نسخه واقعی پروژه تطبیق دهید.
5) migrationها را ابتدا در محیط توسعه اجرا کنید: php artisan migrate
6) تست‌های مربوط به این فاز و جریان‌های وابسته را اجرا کنید.

ملاحظات مهم:
- این ZIP یک ماژول افزایشی است و شامل اسکلت کامل Laravel نیست.
- این فاز به‌صورت مستقل با کل فازهای قبلی یکپارچه یا تست سرتاسری نشده است.
- هر جا به مدل/رابطه/ستون قبلی وابسته است، پیش از اجرا آن را با schema واقعی تطبیق دهید.
- برای انتشار واقعی، تست دسترسی، اعتبارسنجی، محدودسازی نرخ، مدیریت خطا و تست خودکار ضروری است.
- قبل از اجرای migration روی داده واقعی، backup بگیرید.
