چک‌لیست انتشار Marketplace Pro
==============================

قبل از انتشار
-------------
[ ] تمام migrationها روی نسخه staging اجرا و rollback آن‌ها بررسی شود.
[ ] تست‌های Unit و Feature برای پرداخت، سبد، سفارش چندفروشنده، کوپن، کیف پول، ارسال و مرجوعی اجرا شود.
[ ] callback درگاه فقط با verify سمت سرور سفارش را paid کند.
[ ] کلیدها و رمزها فقط در Environment/Secret Manager باشند.
[ ] APP_DEBUG=false و APP_ENV=production تنظیم شود.
[ ] HTTPS، کوکی امن، CSRF و محدودسازی نرخ فعال باشد.
[ ] دسترسی پنل مدیر و فروشنده با Policy/Gate تست شود.
[ ] برای آپلود فایل محدودیت نوع، حجم و نام‌گذاری امن اعمال شود.
[ ] صف‌ها با worker دائمی و retry/backoff مناسب اجرا شوند.
[ ] کش config/route/view پس از deploy بازسازی شود.
[ ] backup خودکار دیتابیس و فایل‌ها و تست بازیابی انجام شود.
[ ] مانیتورینگ خطا، لاگ، سلامت صف و پرداخت برقرار باشد.
[ ] سیاست حفظ داده، حریم خصوصی، شرایط مرجوعی و مالیات بررسی شود.

فرمان‌های متداول Laravel
------------------------
php artisan test
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan migrate --force

توجه
----
این چک‌لیست به معنی تست یا تأیید امنیت پروژه نیست. قبل از انتشار عمومی، بازبینی مستقل کد و تست بار لازم است.
