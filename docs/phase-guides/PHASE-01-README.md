# Marketplace Pro — فاز اول

مارکت‌پلیس دوحالته (فروش مستقیم مدیر + فروشندگان مستقل)، فارسی/انگلیسی، Laravel 12.

## وضعیت این بسته
این ZIP شامل سورس‌های اختصاصی فاز اول است و به‌تنهایی جایگزین اسکلت رسمی Laravel نیست. برای جلوگیری از حذف فایل‌های پایه فریم‌ورک، ابتدا اسکلت استاندارد Laravel را بسازید و سپس فایل‌های این بسته را روی آن کپی کنید.

## نیازمندی‌ها
- PHP 8.3+
- Composer 2
- MySQL 8+
- Node.js 20+ و npm

## نصب صحیح
1. یک پروژه خالی Laravel 12 بسازید:
   ```bash
   composer create-project laravel/laravel marketplace-pro "^12.0"
   ```
2. محتوای ZIP این بسته را در پوشه `marketplace-pro` استخراج و فایل‌ها را با فایل‌های موجود ادغام/جایگزین کنید.
3. در ریشه پروژه:
   ```bash
   cp .env.example .env
   ```
   اطلاعات اتصال MySQL را در `.env` تنظیم کنید.
4. اجرا:
   ```bash
   composer install
   php artisan key:generate
   php artisan migrate --seed
   npm install
   npm run build
   php artisan serve
   ```
5. سایت: http://127.0.0.1:8000

## نقش‌ها
- customer: مشتری
- seller: فروشنده
- admin: مدیر کل

## چندفروشندگی
در جدول `products` مقدار تهی `seller_id` یعنی محصول متعلق به فروشگاه اصلی است؛ در غیر این صورت محصول متعلق به فروشنده مشخص‌شده است.

## محدودیت‌های فعلی
این فاز، پایه دیتابیس و ویترین اولیه است. افزودن به سبد خرید، ثبت سفارش، اتصال درگاه بانکی، پنل‌های کامل مدیر/فروشنده، احراز هویت و تست‌های جامع هنوز در فازهای بعدی پیاده‌سازی می‌شوند. پرداخت واقعی یا امنیت عملیاتی را تا تکمیل آن بخش‌ها فعال نکنید.
